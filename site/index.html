核心准则

  1. 所有资料无偿分享，禁止商业化。
  2. 尊重原作者和贡献者，按投稿意愿保留署名。
  3. 不公开个人隐私、受限制材料和明显不适合传播的内容。
  4. 资料仅作学习参考，不保证完整性、准确性或时效性。

免责声明

仓库资料来自公开整理和同学投稿，仅用于学习交流。课程安排、考试范围和参考答案可能发生变化，请以任课教师和学校发布的信息为准。

如资料涉及权利或隐私问题，请通过 GitHub Issues 说明文件路径与处理诉求，维护团队会及时核查。反馈时请勿公开个人隐私；如涉及敏感内容，可先联系维护者沟通处理。
