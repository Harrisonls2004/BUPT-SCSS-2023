# BUPT-SCSS-2023 · 北邮网安学习资料库

> 把学过的课、整理过的资料，留给后面的同学。

[访问资料平台](https://harrisonls2004.github.io/BUPT-SCSS-2023/)

这里是北京邮电大学网络空间安全学院2023级本科课程资料库。我们把上课、写作业、做实验和准备考试时积累的资料整理在这里，包括课程介绍、课件、笔记、作业解答和历年试题，希望学弟学妹们找资料时能方便一点。

网页版支持按学期、课程、资料分类和文件格式查找，也可以直接搜索课程或文件名。各门课的 README 整理了老师、开设学期、分数占比和注意事项，保留了我们当时的学习感受，供大家选课和复习时参考。

## 项目目的

- **方便查找**：把分散的课件、笔记和试题放在一起，少花点时间到处找资料。
- **分享经验**：记录课程要求、实验安排和备考感受，让后来选课的同学有个参考。
- **继续传下去**：按学期和课程整理，也欢迎后面的同学补充自己年级的新情况。
- **一起完善**：资料有遗漏、分类有问题，或者答案写错了，都欢迎指出。

| 内容 | 说明 |

| 历年试题 | 各科考试真题、回忆版试题和复习范围 |

英语、体育和公选课的经验放在[英语体育公选课](英语体育公选课/README.md)目录中。

## 核心准则

1. **无偿分享**：资料用于学习交流，项目不收取任何费用。
2. **拒绝收费**：请勿以本项目名义售卖资料、开展收费服务，或冒充维护者收费。
3. **尊重贡献者**：尊重原作者和投稿者，按投稿意愿保留署名，引用时注明来源。
4. **保护隐私**：提交前请移除学号、联系方式、账号凭据等个人或敏感信息。
5. **合规共享**：不要上传无权公开的材料、受限制内容以及明显不适合传播的资料。

## 参与共建

欢迎一起补充和整理：

- 课程笔记、课件、实验参考和往年试题；
- 新年级的课程安排、考核变化和选课经验；
- 资料分类、文件名、答案和链接的校对；
- 网页功能改进和使用反馈。

不一定要提交一整套资料。一份笔记、一道题的勘误，或者一条课程更新，都很有帮助。

## 资料投稿

1. **Fork 仓库**：将资料放入对应的“学期 / 课程”目录；新增课程可以创建同名文件夹。
2. **提交 Pull Request**：说明新增或修改了什么，注明资料来源；课程经验尽量写清对应年级和任课老师。
3. **提出建议**：如果不方便提交代码，可以通过 [GitHub Issues](https://github.com/Harrisonls2004/BUPT-SCSS-2023/issues) 反馈缺失资料、错误或改进建议。

需要署名时，请在 Pull Request 中注明希望使用的名字或昵称；也可以说明希望匿名。请不要在公开的 Issue 或提交记录中留下个人隐私信息。

## 免责与合规说明

仓库资料来自个人整理、公开分享和同学投稿，仅用于学习交流。课程安排、考试范围、评分比例和参考答案可能随年级、老师或时间变化，资料也可能有遗漏或错误，请以任课教师和学校发布的信息为准。

课程介绍里“给分高不高”“难不难”等评价，都是我们或其他同学当时的个人感受，不代表之后每一届的情况。作业、实验和代码请作为理解思路的参考，按课程要求独立完成自己的任务。

本项目没有开展资料售卖或收费辅导。如有人以本项目名义收费，请注意甄别。

如资料涉及权利或隐私问题，请通过 [GitHub Issues](https://github.com/Harrisonls2004/BUPT-SCSS-2023/issues) 或下方联系方式说明文件路径与处理诉求，我们会核查处理。涉及敏感信息时，请先联系维护者，不要把隐私内容公开到 Issue 中。

仓库许可见 [LICENSE](LICENSE)。第三方资料的权利归原作者所有，使用时请遵守其各自的授权和使用要求。
